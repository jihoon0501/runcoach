# RunCoach (RunLog)

삼성 헬스의 러닝 기록과 수면·심박 같은 건강 신호를 함께 보고, 내 몸 상태에 맞는 훈련 계획과 피드백을 만들어 주는 안드로이드 러닝 코치 앱이에요. (Kotlin, Jetpack Compose)

- 패키지명: `io.github.jihoon0501.runcoach`
- 데이터는 사용자의 폰 안에서만 저장·계산해요. Claude API 키를 직접 입력한 경우에만 평가 요청 때 러닝 기록 요약이 Anthropic으로 전송돼요.
- 의료 기기가 아니며, 앱의 계획·평가는 일반적인 운동 가이드예요.

## 주요 기능
- 첫 실행 안내: 내 정보(키·체중·나이·목표), 삼성 헬스 연동, 알림 허용
- 러닝 기록 분석: 구간별 페이스·심박·케이던스, 준비운동/본운동/마무리 구성, 월별 보기
- 훈련 계획: 피로도와 최근 기록에 맞춰 이지런·템포·인터벌·롱런을 구성하고, 바뀐 이유를 설명
- 오늘 컨디션: 수면·에너지 점수·야간 심박을 내 평소 기록과 비교
- 걷기 반영: 러닝 통계와 분리하되 부하·회복 걷기 판정에 반영
- 구글 캘린더 공유, 훈련 알림, (선택) Claude AI 평가

## 이 저장소에 들어 있는 것 / 없는 것
소스 코드와 문서의 **스냅샷**이에요. 아래는 포함하지 않았어요.

- Gradle 빌드 설정(`build.gradle.kts`, `settings.gradle.kts` 등)과 리소스(`res/`: 아이콘, 폰트)
- 삼성 헬스 Data SDK(`.aar`): 삼성 약관에 동의하고 내려받아야 하는 파일이라 재배포하지 않아요
- 서명 키, API 키, 개인 건강 데이터

## 폴더
- `app/src/main/java/io/github/jihoon0501/runcoach/` 앱 소스
- `docs/` 배포·삼성 헬스 파트너 등록 준비 문서

## 삼성 헬스 연동에 대해
삼성 헬스 Data SDK는 공개 배포하려면 삼성의 사전 등록(패키지명 + 서명 SHA-256)이 필요해요. 등록 전에는 개발자 모드가 켜진 기기에서만 동작해요. 자세한 내용은 `docs/삼성-파트너등록-준비.md`를 보세요.

## 라이선스
아직 정하지 않았어요. 라이선스 파일이 없는 동안은 모든 권리를 작성자가 가져요.
