# RunCoach (RunLog)

삼성 헬스의 러닝 기록과 수면·심박 같은 건강 신호를 함께 보고, 내 몸 상태에 맞는 훈련 계획과 피드백을 만들어 주는 안드로이드 러닝 코치 앱이에요. (Kotlin, Jetpack Compose)

- 패키지명: `io.github.jihoon0501.runcoach`
- 데이터는 사용자의 폰 안에서만 저장·계산해요. Claude API 키를 직접 입력한 경우에만, AI 평가나 코치 대화를 요청할 때 러닝 기록·계획·피로도 요약과 대화 내용이 Anthropic으로 전송돼요. 자세한 내용은 [개인정보처리방침](docs/privacy.html)을 보세요.
- 의료 기기가 아니며, 앱의 계획·평가는 일반적인 운동 가이드예요.

## 주요 기능
- 첫 실행 안내: 내 정보(키·체중·나이·목표), 삼성 헬스 연동, 알림 허용
- 러닝 기록 분석: 구간별 페이스·심박·케이던스, 준비운동/본운동/마무리 구성, 월별 보기, 경로 지도와 플레이백, 페이스 색상 달력
- 훈련 계획: 피로도와 최근 기록에 맞춰 이지런·템포·인터벌·롱런을 구성하고, 바뀐 이유를 설명
  - 점진 상승: 4주마다 한 단계씩(최대 5단계), 목표(5K·10K·하프·풀)별 상한과 주간 거리에 연동된 상한
  - 지난 4주에 계획한 인터벌·템포를 얼마나 소화했는지에 따라 단계와 거리를 올리거나 유지하거나 내려요
  - 소화한 인터벌·템포의 실제 페이스와 심박으로 목표 페이스를 조금씩 보정해요
  - 컨디션이 나쁘면 가까운 훈련을 낮추고, 계획 탭에서 "원래대로" 되돌릴 수 있어요
- 크로스 트레이닝: 사이클·수영·근력·구기 등 43종을 상단 칩으로 바로 기록하고, 러닝 환산 부하로 피로도에 반영
- 오늘 컨디션: 수면·에너지 점수·야간 심박을 내 평소 기록과 비교
- 걷기 반영: 러닝 통계와 분리하되 부하·회복 걷기 판정에 반영
- 구글 캘린더 공유, 훈련 알림
- (선택) Claude AI 평가와 코치 대화: 오늘 훈련 변경·추가·쉬기를 제안하고, 확인해야 적용돼요

## 이 저장소에 들어 있는 것 / 없는 것
소스 코드와 문서의 **스냅샷**이에요. 아래는 포함하지 않았어요.

- Gradle 빌드 설정(`build.gradle.kts`, `settings.gradle.kts` 등)과 리소스(`res/`: 아이콘, 폰트)
- 삼성 헬스 Data SDK(`.aar`): 삼성 약관에 동의하고 내려받아야 하는 파일이라 재배포하지 않아요
- 서명 키, API 키, 개인 건강 데이터
  - Google Maps API 키는 `local.properties`의 `MAPS_API_KEY`로 주입해요. 설정 방법은 [notes/maps-api-key.md](notes/maps-api-key.md)를 보세요.

## 폴더
- `app/src/main/java/io/github/jihoon0501/runcoach/` 앱 소스
- `docs/` 앱 소개와 개인정보처리방침 웹페이지 (GitHub Pages)
- `notes/` 배포·삼성 헬스 파트너 등록·Health Connect·파일 가져오기·지도 키 설정 문서
- `tools/` 안드로이드 없이 로직을 시험하는 도구들
- `archive/` 지금은 쓰지 않는 기능(펫)을 보관한 곳

## 로직 시험 (tools/plan-sim)
훈련 계획 엔진(`PlanEngine.kt`)을 안드로이드 없이 컴파일하고, 가상 러닝 기록으로 "계획 → 소화 → 다음 계획", 컨디션 저하 시 훈련 낮추기, 코치 대화의 계획 변경, 크로스 트레이닝 부하, 하프 목표를 시뮬레이션해요. `kotlinc`(Kotlin 2.x)와 JDK가 필요해요.

```
bash tools/plan-sim/run.sh
```

## 삼성 헬스 연동에 대해
삼성 헬스 Data SDK는 공개 배포하려면 삼성의 사전 등록(패키지명 + 서명 SHA-256)이 필요해요. 등록 전에는 개발자 모드가 켜진 기기에서만 동작해요. 자세한 내용은 [notes/samsung-partner-prep.md](notes/samsung-partner-prep.md)를 보세요.
