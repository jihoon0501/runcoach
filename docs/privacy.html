1. 앱이 다루는 정보

구분항목시점
이용자가 직접 입력닉네임(선택), 출생연도(선택), 성별(선택), 키, 체중, 최대 심박(선택), 목표 종목과 기록, 주당 러닝 횟수, 요즘 주간 거리, 관절 부담 선호첫 실행 화면, 설정
삼성 헬스에서 읽음 (읽기 전용)러닝·걷기 운동 기록(거리, 시간, 페이스, 심박, 케이던스, 구간 기록), 수면, 심박, 에너지 점수, 피부 온도이용자가 삼성 헬스에서 권한을 허용한 경우

삼성 헬스에는 어떤 데이터도 쓰거나 수정하거나 삭제하지 않아요.

2. 이용 목적

  • 러닝 기록 분석, 훈련 계획 생성과 조정, 피로도와 오늘 컨디션 계산
  • 훈련 알림, 구글 캘린더 일정 공유
  • (선택) AI 평가

광고, 마케팅, 프로파일링, 분석 도구, 비정상 종료 수집 도구는 사용하지 않아요.

3. 저장 위치와 보관 기간

  • 모든 정보는 앱의 기기 내 전용 저장 공간에만 저장돼요. 기기 백업(클라우드 백업)에도 포함되지 않도록 설정했어요.
  • 설정의 '내 데이터 모두 지우기'를 누르거나 앱을 삭제하면 저장된 정보가 삭제돼요.
  • 삼성 헬스와 구글 캘린더에 있는 원본 데이터는 이 앱이 지우지 않아요. 캘린더에서는 앱이 만든 훈련 일정을 추가·수정·삭제하고, 같은 기간에 이전에 같은 형식으로 등록된 훈련 일정은 새 일정으로 교체할 수 있어요.

4. 외부 전송 (선택 기능: Claude AI 평가)

이용자가 직접 Anthropic API 키를 입력해서 AI 평가를 켠 경우에만, 평가나 계획 검토를 요청할 때 아래 정보가 Anthropic의 서버로 전송돼요.

전송하는 것전송하지 않는 것
해당 러닝의 요약과 최근 러닝 이력(날짜, 거리, 페이스, 심박, 케이던스, 구간), 나이·성별·키·체중·목표·최대 심박·훈련 선호, 앱이 계산한 피로도·회복 판단·컨디션 점수와 단계, 훈련 계획 요약과 바뀐 이유, 걷기 합계 요약 닉네임, 수면 시간·야간 심박·에너지 점수·피부 온도 같은 건강 데이터의 원래 수치
  • API 키는 이용자의 기기에만 저장되고 Anthropic 인증에만 쓰여요. 사용 요금은 이용자의 Anthropic 계정에 부과돼요.
  • Anthropic의 정보 처리는 Anthropic의 개인정보 처리방침(https://www.anthropic.com/legal/privacy)을 따라요.
  • API 키를 입력하지 않으면 이 전송은 일어나지 않고, 기기 안에서 계산하는 기본 코치가 평가해요.

5. 제3자 제공

운영자는 이용자의 정보를 수집하지 않으므로 제3자에게 제공하지 않아요. 위 4번의 전송은 이용자가 직접 켠 기능에서 이용자의 키로 이루어지는 전송이에요.

6. 이용자의 권리와 선택

  • 삼성 헬스, 알림, 캘린더 권한은 폰 설정에서 언제든 철회할 수 있어요. 철회하면 해당 기능은 쓸 수 없고 나머지는 계속 동작해요.
  • 앱 안에서 내 정보를 수정하거나 모든 데이터를 삭제할 수 있어요.

7. 의료 면책

앱의 훈련 계획, 평가, 컨디션 점수는 일반적인 운동 가이드이며 의료 기기나 의료 조언이 아니에요. 가슴 통증, 어지러움, 비정상적인 심박 같은 증상이 있으면 운동을 멈추고 전문가와 상담하세요.

8. 이용 연령

이 앱은 만 18세 이상 이용자를 대상으로 해요.

9. 방침의 변경

방침이 바뀌면 이 페이지의 시행일을 고치고, 중요한 변경은 앱 안에서도 알려요.

English summary

RunCoach is an Android running coach that reads running/walking sessions and a few recovery signals (sleep, heart rate, energy score, skin temperature) from Samsung Health, read-only, after the user grants permission. Everything the user enters and everything the app reads is stored and processed only on the user's device; the developer operates no server and collects no data. The app contains no ads, analytics or crash-reporting SDKs. If, and only if, the user enters their own Anthropic API key, a summary of a run, recent run history, profile basics (age, sex, height, weight, goal, max heart rate) and app-computed scores are sent to Anthropic when the user requests an AI evaluation; nickname and raw sleep/heart-rate/energy-score/skin-temperature values are not sent. Users can revoke permissions at any time and delete all local data in Settings or by uninstalling. The app is a general fitness guide, not a medical device, and is intended for users aged 18 and over. Contact: jihoon0501@gmail.com.
