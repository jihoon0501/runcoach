# 파일 가져오기 (FIT / GPX / TCX)

## 무엇을 하나
- 설정 탭 → "파일에서 가져오기"에서 파일을 고르면(여러 개 가능, 최대 200개) 러닝·걷기 기록으로 바꿔 앱에 저장해요.
- 삼성 헬스, Health Connect와 **함께** 쓸 수 있어요. 가져온 기록은 `imported_runs.json`에 따로 보관해서, 동기화나 "전체 다시 불러오기"를 해도 남아요.
- 같은 운동이 이미 삼성 헬스/Health Connect로 동기화돼 있으면(시작 시각이 2분 안) 동기화된 쪽을 쓰고, 같은 파일을 다시 가져와도 중복으로 건너뛰어요.
- "가져온 기록 지우기" 또는 "내 데이터 모두 지우기"로 삭제돼요.

## 읽는 방식
| 형식 | 읽는 값 | 비고 |
|---|---|---|
| FIT | 기록(시간, 거리, 속도, 심박, 케이던스, 좌표), 세션(종목, 요약 거리·심박·케이던스) | 개발자 필드, 압축 타임스탬프, 이어 붙은 파일 처리. 종목은 세션의 sport(러닝 1, 걷기 11) |
| GPX | 시각, 좌표, 심박(`hr`), 케이던스(`cad`), 트랙 이름·종류 | 거리는 좌표 사이 거리로 계산 |
| TCX | 시각, 누적 거리, 심박, 케이던스(`Cadence`·`RunCadence`), Sport | Lap 합계의 DistanceMeters와 Trackpoint 값을 구분 |

- **GPS 좌표는 거리·속도 계산에만 쓰고 버려요** (저장하지 않아요).
- 종목 정보가 없거나 애매하면 평균 속도로 추정해요: 1.8~5.0 m/s 러닝, 0.8~1.8 m/s 걷기, 그 밖은 건너뜀. 자전거·수영·하이킹으로 적힌 파일은 건너뛰어요.
- 케이던스는 파일에 한 발 기준(보통 80~100)으로 적힌 경우가 많아서 120 미만이면 2배로 환산해 보여요.
- 속도 기록이 30개 이상이면 걷기/조깅/달리기 구간과 1km 구간을 삼성 쪽과 같은 방식으로 계산해요. 없으면 요약만 보여요.
- 외부 개체(DOCTYPE)가 들어 있는 XML은 거부해요.

## 지원하지 않는 것
- zip으로 묶인 대량 내보내기 파일(가민 계정 전체 내보내기 등): 풀어서 FIT 파일을 고르세요.
- Apple 건강 앱의 내보내기(export.xml): 형식이 달라서 읽지 않아요. 애플워치 운동 GPX를 따로 내보내면 읽을 수 있어요.
- "다른 앱에서 공유" 버튼으로 바로 열기: 아직 없어요 (파일 선택으로만).

## 시험 (`tools/file-import-test`)
가짜 파일로 해석 코드를 실제로 컴파일해서 시험했어요 (FIT, GPX, TCX 러닝·걷기, 종목 정보 없는 GPX, 개발자 필드·압축 타임스탬프가 있는 FIT).
- 세 형식 모두 같은 러닝으로 인식: 거리 약 2.93km, 평균 심박 140, 케이던스 85→170, 구간 5개, 1km 구간 2개
- 오류 파일(깨진 FIT, 잘린 FIT, 빈 GPX, 텍스트 파일, 외부 개체 XML)은 앱이 멈추지 않고 오류 문구를 돌려줘요.
- **실제 가민·코로스·폴라 파일로는 아직 시험하지 못했어요.** 기기마다 필드가 조금씩 달라서 실제 파일로 확인이 필요해요.
